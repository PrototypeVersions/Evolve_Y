## Status

This is a concept website, not a live financial service, investment offer, membership program or adopted corporate charter. Proposed capabilities and illustrative numbers are labeled. No source-site corporate relationships, financial claims or technical capabilities are independently audited by this project. The research page states coverage and limitations.

## Build and preview

The site is intentionally static and dependency-free. All HTML is generated by a standard-library Python script. CSS and browser JavaScript are edited directly.

```sh
python3 build.py
python3 -m http.server 8765
```

Open `http://localhost:8765/`. No secrets or environment variables are required.

## Publish

GitHub Pages: deploy from branch `main`, folder `/ (root)`. `.nojekyll` is included. Paths are relative for repository hosting. No framework, package installation or custom Actions workflow is needed.

## Privacy and accessibility

No accounts, analytics scripts or data submissions. Manrope is loaded from Google Fonts; the privacy section discloses those requests. Interactive values remain in the current page. Host logs and external destination sites remain subject to their own policies. Semantic navigation, keyboard-operable tabs, labeled controls, reduced-motion support, responsive layouts and print styles are included.

## Economics model

Revenue = customer count × monthly subscription. Subtract direct delivery cost and fixed costs. Apply a simplified tax provision to positive operating profit, retain the selected reserve, and allocate a chosen proportion of the remaining positive surplus to participants/community. Loss cases produce zero distributable surplus. The model is not a forecast or a full financial statement; it does not infer that fixed costs stay constant at scale.

The proposed sharing split in the demonstration is 65% of the common pool for eligible members and 35% for community access. Final rights require separate enforceable arrangements.

## Source review

44 Rousix and 22 Federal Reserve Black public pages were reviewed through retrieved page text and direct browser inspection. Menu, footer and body links were used; sitemaps were inaccessible. Embedded videos, image-only content, every attachment and external services were not exhaustively audited. Some retrieved source versions were cached. See `research.html` for details.
